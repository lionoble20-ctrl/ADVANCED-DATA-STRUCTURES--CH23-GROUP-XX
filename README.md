as a group we have build a url shotener system 
A URL shortener converts a long, complex web address into a brief, unique link that redirects users to the original destination.
URL shorteners solve practical challenges across marketing, logistics, and infrastructure, operating within high-throughput real-world environments.
Practical Applications & Real-World Uses
Character Limit Management & Visual Cleanliness

SMS & Messaging: Mobile carriers charge or split messages based on the 160-character GSM limit. Converting a 120-character link with UTM trackers down to 15 characters saves costs and prevents message fragmentation.

Social Platforms: Clean, concise links fit cleanly inside post length limits (e.g., X/Twitter) and look better in printed ads, billboards, or slide presentations.
